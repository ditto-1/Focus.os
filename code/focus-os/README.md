# FOCUS.OS

A pixel-art productivity and focus system designed to make task management feel more like a small game than a traditional productivity app.

## Features

- ?? **Quest-based task planning** — turn tasks into manageable quests
- ?? **Focus sessions** — structured sessions for deep work
- ?? **Pixel Pet** — interact with and evolve a virtual companion
- ?? **Daily streaks** — track consistency over time
- ?? **Sensory tools** — ambient sounds and focus-friendly experiences
- ?? **Routine management** — create and manage recurring routines
- ?? **What Should I Do Now?** — helps choose the next task
- ?? **Cartridge Memory** — persistent productivity data
- ?? **Settings** — customize the experience

## Tech Stack

- React
- TypeScript
- Vite
- Node.js
- CSS
- Local application state and persistence

## Development

FOCUS.OS was developed incrementally, with features added and refined across multiple development iterations. The Git history documents the evolution of the application from its initial interface through task planning, authentication, sensory tools, settings, pet evolution, and streak tracking.

## Team Project

FOCUS.OS was developed as a collaborative software engineering project.
